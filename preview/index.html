Cotes Discogs (musique)

Jeton personnel, à générer sur discogs.com → Settings → Developers → Generate new token. Il reste sur ce téléphone. Pour tout ce qui est disque, Discogs remplace l'estimation de l'IA par le prix réellement pratiqué et le nombre d'exemplaires en vente.

Sets LEGO (Rebrickable)

Clé gratuite et immédiate : rebrickable.com → ton profil → Settings → API → Generate. Rebrickable ne publie pas de prix — il donne le nombre de pièces et de figurines, les deux chiffres qui font vraiment la valeur d'un set d'occasion.

Barème de revendeur, à corriger avec tes propres ventes.

Sets LEGO (Brickset)

Clé gratuite sur demande : brickset.com → ton compte → API → Request a key. Brickset donne les mêmes pièces et figurines que Rebrickable, plus le prix de vente neuf officiel LEGO. Sert de second avis quand tu n'as pas de clé Rebrickable — les deux ne s'affichent jamais en double sur une même fiche.

Brickset bloque les appels directs depuis un navigateur — contrairement à Discogs et Rebrickable. La clé seule ne suffit donc pas : il faut un relais gratuit qui transmet la requête à ta place. Deux minutes, une fois :
1. dash.cloudflare.com (compte gratuit) → Workers & Pages → Create → « Hello World ».
2. Colle le code ci-dessous à la place de l'exemple, dans l'éditeur du navigateur, puis Deploy.
3. Colle l'adresse en *.workers.dev qu'il te donne dans le champ juste en dessous, et reteste.

💬 Négociation (La mécanique)

1Offre 50 à 60 % du prix affiché. Tope à 70 %. Au-delà, tu paies le prix de revente.
2Groupe toujours : « je prends ces quatre-là, 20 € et c'est fait » marche mieux que quatre marchandages.
3Espèces, petites coupures, montant exact déjà en main. Un billet tendu conclut une hésitation.
4Visage neutre, même sur une pépite. Dès que tu t'illumines, le prix se fige.
5Un seul chiffre, puis tu te tais. Le silence fait le travail à ta place.

⚠️ Pièges Fréquents

Cartouches repro : Étiquette trop nette, vis cruciforme. Nintendo utilise du tri-wing 3,8 mm. Le plastique d'origine est mat.
Corrosion de piles : Ouvre toujours la trappe. Le vert ronge les contacts et coûte plus cher que l'objet.
Boîte pleine, jeu absent : Ouvre tout. Le boîtier PS2 avec un disque de karaoké dedans est un classique.
Le lot piège : Trois bons objets sur le dessus, du remplissage en dessous. Retourne le carton avant d'annoncer un prix.
